# AIRPLAY02 v0.2.0 candidate — startup tone removal and PCM baseline

**Status:** Source candidate; package and hardware validation pending.

## Changes

- Removed the automatic five-second startup tone. Until streamed PCM is ready, the app now queues silence.
- Kept the independent diagnostic tone source and test, but removed it from the standalone receiver link list.
- Set app/package version defaults to `0.2.0` and SFO `APP_VER` to `00.40`, continuing the existing SFO sequence.
- Added a host test that measures the production PCM ring's 44.1 kHz to 48 kHz output at six frequencies.

## PCM quality baseline

Sanitized host runs on Mac and Lima produced 48,000 output frames per case, no underflows, and no dropped frames. SNR was 92.30 dB at 100 Hz, 54.64 dB at 1 kHz, 26.78 dB at 5 kHz, 15.03 dB at 10 kHz, 8.47 dB at 15 kHz, and 4.17 dB at 20 kHz. This quantifies the current linear interpolation behavior on synthetic tones; it does not identify the root cause of physical-console artifacts.

## Validation boundary

The complete Lima host/sanitizer suite and PPU component compilation passed. It covers protocol/crypto/session/SDP/mDNS, bounded RTSP/RTP loopback, encrypted RTP through decrypt/ALAC/PCM, malformed ALAC mutations, RTSP diagnostics, FFmpeg ALAC fixture decode, PCM ring quality and gain, diagnostic-tone utility, and PPU object architecture. Standalone ELF/PKG build and extraction checks are pending. The PS3 was not touched or launched in this pass. Therefore no current display, controller, AirPlay, or audible playback result is available for this candidate.
