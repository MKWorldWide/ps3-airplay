## Reporting rules

- Distinguish upstream source facts, project measurements, and inferences.
- Link to public sources and pin revisions when a claim depends on source code.
- Do not include hostnames, personal paths, private network details, console/account identifiers, credentials, or unredacted logs.
- Keep test evidence reproducible without exposing private device information.
