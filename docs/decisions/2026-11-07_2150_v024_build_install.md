## Risks introduced

Each launch may add up to 16 KiB to the PS3 log; this version intentionally does not rotate or delete prior sessions. Menu-time flips may still fail to make VSH's overlay visible and may produce flicker while the system menu is open.

## Decision record

### Install without remote launch

- **Decision:** Install and verify the package, then hand off the first launch to the user.
- **Context:** A webMAN launch request previously returned HTTP success without starting the app; XMB launch is the reliable verification path.
- **Options considered:** Treat an HTTP response as a launch, or separate install verification from runtime launch.
- **Why this option was chosen:** Fresh APP_START and user-visible controller behavior are required to prove launch and PS-menu behavior.
- **Tradeoffs accepted:** Hardware behavior remains pending until the user starts the title.
