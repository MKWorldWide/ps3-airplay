## Decision record

### Decision

Build v0.1.13 from the committed main revision, preserve the existing version, and do not deploy while the target endpoints are unavailable.

### Context

The preceding RPCS3 run could not bind UDP 5353 due to host mDNS ownership. Native PS3 behavior remains untested. Interactive RPCS3 testing is pending, and the PS3 did not answer the read-only reachability probe.

### Options considered

- Change code to work around the host's UDP 5353 ownership.
- Install a missing image package in Lima and regenerate an asset already available byte-for-byte.
- Produce a committed-source release candidate and wait for the normal emulator/console test surfaces.

### Why this option was chosen

The host service conflict does not imply a PS3 defect. Reusing a source-matched generated asset avoids unnecessary environment mutation, while package integrity checks validate the candidate without claiming runtime success.

### Tradeoffs accepted

The v0.1.13 package is ready for testing but no live RPCS3/PS3 result is available yet. The next unused package version is v0.1.14.
