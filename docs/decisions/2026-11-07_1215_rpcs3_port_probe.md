## Decision record (embedded)

### Decision: Keep the production port unchanged and use the existing emulator override

- **Decision:** Build the RPCS3 probe with `RTSP_PORT=5001` and retain production TCP 5000.
- **Context:** RPCS3 returned bind failure on port 5000; host inspection confirmed it was occupied. v0.1.25 on port 5001 opened RTSP and RTP sockets and responded to OPTIONS.
- **Options considered:** Stop the unrelated host listener; change the production default; or use the existing build-time port override for the emulator only.
- **Why this option was chosen:** It preserves unrelated host services and keeps PS3 behavior aligned with the RAOP default while still testing app networking.
- **Tradeoffs accepted:** This emulator package is not a physical-console deployment candidate and does not solve RPCS3 mDNS multicast-interface failure.

### Decision: Treat emulator mDNS failure as an environment boundary pending isolation

- **Decision:** Record the stage 6 / error 125 result and do not patch production mDNS logic yet.
- **Context:** RPCS3 opens RTSP/RTP sockets but fails when setting its emulated multicast interface.
- **Options considered:** Alter the mDNS source speculatively; alter host multicast services; or preserve the evidence and isolate the RPCS3 behavior separately.
- **Why this option was chosen:** The failure is specific to the emulated interface and does not establish a PS3 defect; the host service must not be disturbed.
- **Tradeoffs accepted:** RPCS3 cannot currently verify discovery, so real PS3 discovery remains a separate test.
