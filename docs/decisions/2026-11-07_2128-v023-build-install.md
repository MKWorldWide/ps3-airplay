## Decision record

### Keep the failed launch boundary explicit

- **Decision:** Record install as verified and launch as pending despite HTTP 200.
- **Context:** The log still ended with v0.2.2 cleanup and the webMAN status showed XMB.
- **Options considered:** Count HTTP 200 as launch success; retry remote launch; hand off to direct XMB launch.
- **Why this option was chosen:** A fresh `APP_START` is the project's evidence boundary, and direct XMB launch avoids speculative retries.
- **Tradeoffs accepted:** Hardware validation now requires one user action.
