## Timestamp in EDT
2026-11-07 1413 source-local America/New_York

## Scope of the pass
PS3 Mbed TLS arithmetic configuration, diagnostic phases, START loop handling, and version 0.1.31 / SFO 00.31.

## Why this pass was needed
Hardware stops inside OPTIONS; exact saved RPCS3 replay faults in bignum multiplication. PPC64 assembly assumes eight-byte pointers while PS3 pointer locals are four bytes.

## Decision record (embedded)
- Decision: disable assembly for the PS3 ABI. Context: 64-bit asm pointer access over 32-bit pointer locals. Options: patch upstream asm or portable implementation. Chosen: portable C to minimize target-specific maintenance. Tradeoff: potential performance loss.
- Decision: keep cryptographic RNG and blinding. Context: failure occurs in arithmetic, not proven RNG failure. Options: bypass crypto or repair ABI. Chosen: repair. Tradeoff: full private operation still required.
- Decision: use checkpoints rather than a receiver-thread rewrite. Context: concrete crash now identified. Options: new concurrency engine or targeted fix. Chosen: targeted fix. Tradeoff: main loop still processes finite crypto work synchronously.
