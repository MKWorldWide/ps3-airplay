## Architecture / logic changes

No receiver code changed during package generation. The package contains source commit `8769324`, APP_VER `0.1.18`, RTSP port 5000, PS3DK v0.27.0 PPU, and the pinned PSL1GHT checkout. Build/package script defaults now target 0.1.19.

## Runtime behavior changes

v0.1.18 adds four numeric PCM status events every five seconds while the ALAC decoder is active. They report buffer occupancy, accepted ring frames, resampler input frames consumed, and frames submitted to GameOS audio blocks. They do not report audible output. Runtime behavior has not yet been tested.

## Decision record

### Decision 1: Generate v0.1.18 from the pushed commit

- **Context:** The telemetry source and PPU build were validated; an artifact must be tied to an exact revision.
- **Options considered:** Stop at the working-tree ELF; package the exact pushed revision; wait for RPCS3 access before building.
- **Why chosen:** A validated package is needed to test emitted metrics later; it can be built without changing emulator settings.
- **Tradeoffs accepted:** The package does not provide runtime telemetry evidence until launched.

### Decision 2: Keep RPCS3 settings and the physical console unchanged

- **Context:** RPCS3 UI was unavailable, and the route test requires separate action-time confirmation.
- **Options considered:** Mutate local emulator settings without GUI; wait and preserve the known configuration.
- **Why chosen:** No network change is needed for package creation, and runtime results should use an observable, authorized setup.
- **Tradeoffs accepted:** Emulator installation and log inspection are deferred until UI access returns.
