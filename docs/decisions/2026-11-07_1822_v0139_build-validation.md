## Decision record (embedded)

### Decision: Keep both v0.1.39 packages as local validated candidates

- **Context:** Exact source built cleanly; RPCS3 UI became inaccessible during install.
- **Options considered:** Replace emulator HDD files manually; retry repeatedly through an inaccessible GUI; preserve the packages and wait for a supported install path.
- **Why this option was chosen:** Direct HDD replacement bypasses RPCS3's package installer and risks confusing installed state. The existing v0.1.38 installation and log remain useful as a known baseline.
- **Tradeoffs accepted:** Emulator runtime validation is delayed; host/build/package evidence is available now.
