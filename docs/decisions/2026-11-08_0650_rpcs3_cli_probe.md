## Decision record (embedded)

### Decision: classify the command-line route as blocked

- **Context:** No output or exit occurred within the bounded probe, and the desktop was locked.
- **Options considered:** Keep trying unverified command-line options; change existing emulator settings; or stop and retain the runtime gate as blocked.
- **Why chosen:** Changing user configuration without a reliable run path is unnecessary, and an unresponsive `--help` probe provides no basis to test a package safely.
- **Tradeoffs accepted:** Emulator lifecycle validation waits for desktop access.
