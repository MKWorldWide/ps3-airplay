## Decision record

### Decision: Install and launch after exact package verification

- **Context:** User authorized installation and launch, and has a standing instruction for automatic package installation.
- **Options considered:** Wait for explicit confirmation; install a separately versioned, hash-verified candidate while retaining rollback packages.
- **Why chosen:** It advances the direct hardware diagnosis while preserving previous packages and the known recovery path.
- **Tradeoffs accepted:** The app must be tested by the user for physical controller behavior; remote logs alone cannot prove a button press.
