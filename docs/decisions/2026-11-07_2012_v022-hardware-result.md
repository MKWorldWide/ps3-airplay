## Decision record

### Decision: Pause further console commands for the user's manual comparison

- **Context:** The user expects webMAN launch might affect controller behavior and explicitly requested to reboot and launch manually.
- **Options considered:** Re-launch remotely with webMAN immediately; exit or relaunch again; preserve logs and wait for the user's manual test.
- **Why this option was chosen:** The manual path is the discriminating observation the user wants; another remote launch would contaminate that comparison.
- **Tradeoffs accepted:** Hardware retest is waiting on the user, but prior logs and exact package identity are preserved.

## Next recommended step

After the user reports the manual launch result, read the new log over FTP and compare it with this run; then fix only the first proven divergence.
