## Decision record (embedded)

### Decision 1: Preserve v0.1.19 as an ignored local artifact and reserve 0.1.20

- **Context:** A validated package has been generated, but emulator runtime cannot be observed while the desktop is locked.
- **Options considered:** Rebuild with an identical version later; keep package files in Git; preserve the exact package locally and advance defaults.
- **Why chosen:** This preserves the tested bytes for future install and prevents a later change from silently reusing the same identity.
- **Tradeoffs accepted:** GitHub source cannot itself serve the generated package artifact; its exact metadata is documented and local artifacts are retained.

### Decision 2: Do not bypass the desktop lock for RPCS3

- **Context:** User authorized local RPCS3 operations, but Computer Use reports that the Mac remains locked and cannot expose the GUI.
- **Options considered:** Retry later when available; claim package checks as runtime validation; manipulate the emulator configuration or try alternate UI unlock methods.
- **Why chosen:** Wait for ordinary desktop availability while continuing independent host/build work. No UI or emulator configuration was modified.
- **Tradeoffs accepted:** Runtime evidence is delayed; package correctness is established only to the structural/build boundary.
