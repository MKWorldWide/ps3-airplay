## Architecture / logic changes

Fixed 160-phase FIR uses bounded history and exact integer phase. Aggregate diagnostics sample service/read-index/render/log costs. Existing display flip state uses a shorter configurable guard, retaining timeout and double-buffer repair.

## Runtime behavior changes

44.1 kHz output has ~0.703ms causal delay; 48k direct path is preserved. Six cost/index aggregates plus elapsed interval are emitted per five seconds. Default post-menu guard is350ms. No console action or transport tuning.

## Validation performed

Host forensic ASan/UBSan suite, independent SciPy reference, deterministic sine/noise/impulse/music, chunk/restart equivalence,600s conservation, multiple menu windows/cycles/callback orders, timing aggregator and log-cost benchmark. Exact-source full Linux/PPU/package gate follows this commit; results must be recorded separately.

## Immediate results

20k analytic SNR improves4.17to75.07dB;64tap best of tested bounded alternatives. Host cost increases~9x yet remains below realtime. Fullband noise comparison25.35dB exposes the finite transition band.350ms mock restoration meets500ms default target. No hardware guarantee.

## Known limitations / follow-ups

True sender/output drift, GameOS cost/deadlines, audible candidate quality and physical compositor behavior remain unmeasured. Build/release gating pending. Existing logs cannot attribute every concealment to actual loss.

## Risks introduced

FIR adds~40KiB coefficient storage,256bytes history,0.703ms delay and processing cost. Short guard may truncate physical fade. No speculative drift loop, transport replacement or console change.
