## Known limitations / follow-ups

- Host timing values come from Lima x86_64 emulation and do not predict PS3 scheduler or filesystem behavior.
- Physical display/resume, network discovery, RTSP compatibility with iPhone, RTP flow, audible output, and clean exit remain unverified for this candidate.
- Game audio mixing remains outside the standalone receiver and is not solved by this pass.

## Risks introduced

- Package title/art changes may have XMB rendering differences that cannot be established from extracted files alone.
- Async logger queue/drop and bounded shutdown-drain behavior require hardware observation under sustained streaming.
- RTP live-edge recovery and re-prebuffer behavior are validated in host fixtures only.

## Decision record

### Decision

Mark the Linux/PPU/package release gate as passed for the candidate, while keeping hardware behavior explicitly unverified.

### Context

The exact committed tree completed the full release script and independent local artifact validators after the strict-host declaration fix.

### Options considered

- Treat package construction as hardware acceptance.
- Report only host build completion and defer all package metadata claims.
- Record the exact PPU/package validations and preserve separate hardware acceptance gates.

### Why this option was chosen

It records what the available evidence proves without conflating structural correctness with launch, display, AirPlay, or audio behavior.

### Tradeoffs accepted

The package can be reviewed and retained now, but no claim is made about physical launch or playback until a separate hardware test.
