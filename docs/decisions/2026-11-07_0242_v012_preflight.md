## Decision record (embedded)

### Preserve v0.1.2 and defer transfer

- **Decision:** Do not rebuild or transfer v0.1.2 in this pass.
- **Context:** Its exact artifact validates locally, but the console is unreachable and its display wait behavior includes unbounded polling after a previous black-screen/forced-shutdown report.
- **Options considered:** Transfer the existing package now; build a new package immediately; complete safe preflight and assess a minimal wait timeout first.
- **Why chosen:** The console cannot be checked read-only, and no need to overwrite a staged file or install anything is established. A bounded display wait may reduce risk before the next human-observed test.
- **Tradeoffs accepted:** Hardware testing is delayed until reachability and whether to retain v0.1.2 or create a safety revision are resolved.

### Keep trace-assisted test status separate

- **Decision:** Mark the receiver loopback test unresolved rather than passing.
- **Context:** The direct run timed out, while tracing changed scheduling and allowed completion.
- **Options considered:** Count the trace pass; classify as a failure; preserve a flaky/unresolved status pending repeats.
- **Why chosen:** Instrumentation can mask a timing race; only repeated uninstrumented completion will establish ordinary host-test reliability.
- **Tradeoffs accepted:** The test suite remains blocked from a green status until diagnosis.
