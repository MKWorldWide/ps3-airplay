## Decision record

### Decision: Stage v0.1.35 without installing during active playback

- **Context:** The latest log still records ALAC frames and no APP_STOP.
- **Options considered:** Install immediately over the running AIRPLAY02 process; wait for clean exit after staging; discard the build and keep listening on v0.1.33.
- **Why chosen:** The package is ready and safely staged, while replacing files under the active app could disrupt playback or leave ambiguous install state.
- **Tradeoffs accepted:** Hardware testing pauses until the app exits; v0.1.34's resend change remains untested separately, bundled in v0.1.35.
